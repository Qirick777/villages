# Villages — 자동 확장 마을 시뮬레이션

수요(Demand) 알고리즘으로 스스로 확장하는 마을 시뮬레이션. **Godot 4.7 (GDScript)**, 좀보이드식 아이소메트릭 2D.

> 개발 계획서 `v1.1` 기반 구현. 이 저장소는 계획서의 **핵심 시뮬레이션 루프(M1~M5 중심)** 를 동작 가능한 수직 슬라이스로 구현한 것이다.

## 실행 방법

1. [Godot 4.3+](https://godotengine.org/) 에디터로 이 폴더를 연다 (`project.godot`).
2. 에디터가 리소스를 임포트하면 **F5**(실행)로 시작.
3. 화면 좌상단 UI에서 배속(⏸/×1/×2/×4/×8)과 시드 재생성을 조작.
   - 카메라: `WASD` 이동, 마우스 우클릭 드래그, 휠 줌.

에셋은 전부 코드 생성 플레이스홀더(다각형)라 별도 리소스 임포트가 필요 없다.

## 동작하는 핵심 루프

- **부트스트랩/맨손 모드**(원칙1): 도구 없으면 효율 25%로 계속 생산 → 데드락 없음.
- **요청 체인**(§6.2): 도구 내구 20% → 장인 요청 → 재료 부족 시 목수/광부 파생 → 창고 재고로 해소.
- **압력 기반 임명/전직**(§6.6~6.7): 신규 성인은 하드제약→최대압력 순으로 직업 결정, 심각한 병목은 히스테리시스+쿨다운 하에 전직.
- **음의 피드백**(원칙2): 인구↑→식량압력↑→식량직↑, 잉여↑→번식→빈집부족→건축가↑.
- **비축 상한/부패**(원칙3): 창고 한도 초과분 자정 부패 → 잉여가 번식·확장으로 흐름.

## 계획서 대비 단순화/생략 (향후 M6)

- 길찾기는 목표 셀 직선 보간(AStarGrid2D 미적용). 건물 실내 층/지붕 페이드 미구현.
- 늑대 습격·청소 잔해는 압력 이벤트 수치만 반영(전용 오브젝트/전투 연출 미구현).
- 자재 요청은 창고 재고 존재 시 충족 처리하는 근사(개별 운반 경로 미시뮬).
- 저장/로드(§9.5), CSV 익스포트(§12), 셰이더 물결·방향성 그림자 미구현.
- 맵 크기 기본 96×96(계획서 목표 256×256, `MapGen.MAP_W/H`로 조정 가능).

이 단순화들은 수요 루프의 정확성을 해치지 않으며, 렌더링/연출/최적화 레이어에 해당한다.

## 결정론

모든 랜덤은 `RNGService` 단일 시드에서만 파생하고 시뮬은 0.5초 고정 틱으로 갱신되므로, 동일 시드는 동일 전개를 재현한다(리플레이/밸런싱 검증 기반).
